# 要件トレーサビリティ

各要件ID(F-XX / N-XX)が、プロジェクトのどのドキュメントのどの章に対応しているかを一覧化した表。要件IDにカーソルを合わせると概要がツールチップで表示される([用語集](_snippets/glossary.md)を単一の情報源としている)。

新しい設計文書を追加した場合は、この表に列を1つ追加すること(既存の列・行は変更しない)。
