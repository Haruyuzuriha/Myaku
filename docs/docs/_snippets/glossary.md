*[N-04]: 開発体制 — 一人での開発。オープンソースとして公開する
*[N-05]: データベース・時系列ストレージ — TimescaleDBを既定バックエンドとするpluggable設計

*[N-07]: 保守性・拡張性 — ワークスペース境界をデータ設計段階から確保(v1は単一ワークスペース固定)
*[N-08]: 認証情報・シークレット管理 — OSネイティブキーチェーン優先、暗号化ローカルファイルへのフォールバック
*[N-09]: パッケージング — 署名付きJAR形式で配布する(JVM前提、ネイティブバイナリは対象外)
